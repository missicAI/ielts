GRAMMAR

Conditional sentences

TypeFormUse / example
ZeroIf + present, presentFacts: If traffic increases, pollution rises.
FirstIf + present, will + VReal future possibility.
SecondIf + past, would + VUnreal present/future.
ThirdIf + past perfect, would have + PIIUnreal past.

Unless = if ... not. As long as / provided that / providing that introduce a necessary condition.

Passive voice

TensePassive form
Present simpleam/is/are + PII
Past simplewas/were + PII
Present perfecthas/have been + PII
Futurewill be + PII
Modalmodal + be + PII

Omit the agent when it is unknown, obvious or unimportant. Put place before time when both appear at the end.
